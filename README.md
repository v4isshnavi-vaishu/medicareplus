# 🏥 LifeCare Hospital – Hospital & Healthcare Website

## 📌 Project Description

LifeCare Hospital is a modern, attractive, and responsive healthcare website developed using **HTML5 and CSS3**. The website provides information about hospital facilities, medical departments, experienced doctors, healthcare services, appointment booking, health tips, and emergency contacts.

It is designed to help visitors easily explore hospital information and learn about the medical services available.

## ✨ Features

- **Home Section:** Attractive hero section with a welcome message and hospital background image.
- **About Hospital:** Displays hospital information, experience, doctors, and medical departments.
- **Medical Departments:** Showcases Cardiology, Neurology, Pediatrics, and Orthopedics.
- **Doctor Profiles:** Displays doctor names, specializations, profile images, and experience.
- **Medical Services:** Includes emergency care, health checkups, pharmacy, and laboratory services.
- **Appointment Booking:** Provides an appointment form to enter patient details and select a department.
- **Health Tips:** Shares useful information about healthy food, exercise, and sleep.
- **Emergency Contacts:** Displays emergency contact information.
